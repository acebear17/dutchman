### Formats

- Open Fusion, Inventor and SolidWorks files straight from SolidCraft with the Dutchman plugin, keeping editable history.
- SolidCraft's Import report lists only what the design lost, one plain line per kind of loss ("Appearances carried over with changes"); notes about how the file was read stay under Details.
- The plugin checks the editable history in SolidCraft itself, so a history that matches the original geometry opens as the visible model.
