### Command line and install

- Attach `dutchman-plugin-X.Y.Z.zip` and `dutchman-plugin.zip` to each release: Dutchman as a
  SolidCraft plugin, which opens Fusion, Inventor, and SolidWorks files in SolidCraft with
  editable history. Install the zip as it is from Preferences > Plugins in SolidCraft 0.44 or
  newer (desktop only for now); see `docs/solidcraft-plugin.md`.
